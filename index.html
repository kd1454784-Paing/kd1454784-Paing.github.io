Zaw Min Paing ( Zaw Paing )

Graphic Designer / Website Designer / 2002.09.24 / Myanmar / Studying in Kobedenshi Collage

私は困難な状況に屈せず、常に情熱を持ってデザインと向き合い、成長し続ける人間です。
ミャンマーで高校（10年生）を卒業後、幼少期からの「描くこと」への情熱をきっかけにグラフィックデザインの道を歩み始めました。独学でPhotoshopやIllustratorを習得し、2022年にマーケティング会社でのインターンからキャリアをスタートしました。努力を重ねた結果、同年にジュニアデザイナー、2023年にはシニアデザイナーへと昇進し、多様なクライアントのプロジェクトを成功に導きました。仕事終わりにもジムで体を鍛えつつ、毎晩YouTubeなどを通じてデザイン理論やモーショングラフィックス、HTML/CSSの基礎を学び続けるなど、成長への努力を怠りませんでした。
母国の厳しい情勢の中でも「大学で学ぶ姿を家族に見せたい」という想い、そして文化や仏教観に親しみのある日本で技術を磨きたいという強い意志から、2024年10月に来日いたしました。日本語学校ではアルバイトと両立しながら出席率98%以上を維持し、現在は神戸電子専門学校にて、日本のプロフェッショナルな思考法と高度なデザイン知識を深めています。
これまでの実務経験と、妥協せず学び続ける行動力を活かし、貴社に貢献できるよう全力を尽くします。
