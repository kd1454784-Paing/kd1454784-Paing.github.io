制作について About this project

概要 Overview
神戸・北野の水族館をテーマにしたWebサイトのデザインです。イベント、チケット、営業時間、アクセスまで、来館前に必要な情報を1ページにまとめました。A website design themed around an aquarium in Kitano, Kobe. One page brings together the events, tickets, hours and access details a visitor needs.
制作 Project
学校の課題 ・ 制作期間 2週間School assignment · 2 weeks
ターゲット Target users
水族館の来館者、特に子どもと家族Aquarium visitors, especially children and families
担当 My role
Figmaでのデザインを担当。コーディングはAIツールを活用しました。I designed the site in Figma and used AI tools for the coding.
使用ツール Tools
Figma（デザイン）、HTML / CSS（AIツールを活用してコーディング）Figma (design), HTML / CSS (coded with AI tools)
デザインのポイント Design choices
  • 深い青の背景とシアンの見出しで、海の中にいるような雰囲気を表現しました。Deep blue backgrounds and cyan headings create the feeling of being underwater.
  • ニュースとイベントはカードに分け、一覧で見やすくしました。News and events sit in separate cards so they are easy to scan.
  • 料金は表にまとめ、区分ごとに比較しやすくしました。Prices are in a table so visitors can compare each ticket type.
学んだこと What I learned
子どもにも伝わるよう、写真とカードで情報を分かりやすく整理する大切さを学びました。I learned how important it is to organize information clearly with photos and cards, so that even children can follow it.
